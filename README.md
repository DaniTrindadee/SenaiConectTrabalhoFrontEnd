# 🌎 Sobre

O **SenaiConect** é uma plataforma desenvolvida para aproximar estudantes, desenvolvedores e profissionais da área de tecnologia.

Inspirada nas maiores redes sociais do mercado, a aplicação oferece um ambiente onde usuários podem compartilhar projetos, conhecimentos, experiências e oportunidades, fortalecendo a comunidade de tecnologia.

Este projeto foi desenvolvido durante o curso de **Front-End do SENAI**, colocando em prática conceitos fundamentais do desenvolvimento web.
